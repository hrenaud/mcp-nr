# Instructions de livraison

## Release obligatoire

Toute modification fonctionnelle ou de configuration destinée à la production doit suivre le cycle complet de livraison : tests, pull request, fusion autorisée explicitement, release patch, tag et push.

Ne pas s'arrêter après les tests, le commit ou la pull request. Si une autorisation explicite est requise pour la fusion, la demander ; une fois obtenue, terminer la release sans attendre une demande distincte.

L'utilisateur peut explicitement demander de ne pas créer de release.

Pour une release, suivre `.claude/skills/mcp-nr-release/SKILL.md`.
